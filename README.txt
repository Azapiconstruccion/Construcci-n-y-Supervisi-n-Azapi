# Construcción y Supervisión AZAPI — Sitio web

## Contenido
- `index.html` — página completa, responsive y lista para publicar.
- `assets/` — logotipo y fotografías proporcionadas para el sitio.

## Publicación
### GitHub Pages
1. Crea un repositorio.
2. Sube `index.html` y la carpeta `assets`.
3. En Settings → Pages, selecciona la rama principal y `/ (root)`.
4. Guarda y espera a que GitHub publique el sitio.

### Hosting tradicional
Sube `index.html` y la carpeta `assets` a la carpeta pública del hosting (normalmente `public_html`).
